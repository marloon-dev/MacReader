# MacReader

Leitor de livros digitais para Android, iPhone e macOS.

> Em desenvolvimento.

## O que vem por aí

- Estante com capas e progresso de leitura
- Leitura de EPUB e PDF
- Temas claro, sépia e escuro
- Ajuste de fonte, tamanho e margens
- Sumário, marcadores e destaques
- Interface em português do Brasil

## Como rodar

Requer Node.js 20 ou mais novo.

```sh
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal (normalmente http://localhost:5173).
